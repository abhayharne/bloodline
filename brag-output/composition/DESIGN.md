# BloodLine film design
Source: Flutter red Material 3 light theme. Public demo values only.
Colors: #160B0D cinematic ground, #FFF8F7 app surface, #FF645B bright red framing accent, #D32F2F critical red, #231918 dark UI ink, #246239 success.
Typography: Archivo Black for film titles; IBM Plex Mono for metadata; Montserrat for the video-sized Material UI adaptation.
Spacing: 110px vertical and 120px horizontal stage padding, 32px panel radii, 23px form gaps. No background filler, floating UI loops, invented impact statistics, guilt-based copy or narration.
