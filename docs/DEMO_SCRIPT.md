# Demo Script (3 minutes)

## Setup (before going on stage)
- API running, `POST /dev/reset` done, 3 devices ready: Phone 1 = Ravi (requester), Phone 2 = Asha (donor, O-), Laptop/Tablet = City Blood Bank.
- Chat inbox empty for Ravi; Asha logged in with the app open on the feed.
- Backup video queued.

## Beats
| Time | Say | Do |
|---|---|---|
| 0:00 | "Every blood emergency in India starts as a WhatsApp forward. Stale, spammy, no one knows if it's done." | Show a messy forwarded message (slide) |
| 0:20 | "BloodLine turns each emergency into its own live room." | Phone 1: Ravi posts O- x2, City Hospital, critical |
| 0:45 | "The nearest bank and matching donors are notified instantly." | Laptop: bank sees the request, confirms stock in chat |
| 1:10 | "Donors get a targeted alert, not a broadcast." | Phone 2: banner appears, Asha taps "I can help" |
| 1:30 | "Everyone coordinates in one place." | Chat: bank says 1 unit ready, Asha shares location pin |
| 2:10 | "When it's done, the room closes. No more noise." | Ravi taps Fulfilled; room becomes read-only |
| 2:30 | "Built on Nexconn Chat SDK in a day. Next: donor verification, compatibility matching, e-Raktkosh integration." | Roadmap slide |
| 2:50 | Ask | Close |

## If something breaks
- Chat not delivering: switch to backup video, narrate over it.
- GPS wrong: use manual lat/lng fields in dev settings.
